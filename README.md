# Random Enchantment Mod

A Bedrock mod that gives players random enchantments every 5 minutes. Perfect for randomizing gameplay and adding unpredictability to your server.

## Features

- Gives players random enchantments every 5 minutes
- Uses vanilla enchantments for compatibility

## Requirements

- Minecraft Bedrock Edition 1.21.4
- Forge 49.0.1

## Installation

1. Download the mod from the releases page.
2. Place the mod in your mods folder.
3. Launch Minecraft Bedrock Edition.

## Usage

Once installed, the mod will automatically give players random enchantments every 5 minutes when they hold an item.

## Configuration

The mod does not have a configuration file. The enchantment interval is set to 5 minutes by default.
